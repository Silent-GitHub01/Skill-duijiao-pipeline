# 实战坑表：双本对校流水线

来源：《老子道德經王弼注精校》（底本，繁，带 `[經文]`/`[注解]` 标记）
×《宋徽宗御解道德真經》（参校本，简）全 81 章对校（2026-09-11）。

## 一、取文通道

| 坑 | 现象 | 解法 |
|---|---|---|
| 用 MCP 取文 | `doc_resolve_document_structure` 每段最多 200 字 preview，`mode=full` 也只有 50~200 字，长注被腰斩，且 JSON 体量爆炸 | 字符级校勘**必须** `extract_docx.py` 直读 `word/document.xml` |
| docx 段落与语义不对应 | 一个 `<w:p>` 可能是一整章注、也可能只是半个句子（原书分页/换行残留） | 先抽全文再按章/标记重组，不要假定「一段一句」 |

## 二、分章与经注分离

1. **噪声行**：参校本每章标题前有孤立汉字数字行（原书页码/计数残留）、`道经上` 分篇行 → 正则剔除。
2. **现代羼入**：参校本夹广告 12 处（10 处贴在注文末尾、2 处独立成段）。
   → 正则清；清洗后为空的段落**保留空占位**，否则段序漂移、`LABEL_OVERRIDE` 全部错位。
3. **覆盖率优于最长子串**：
   - `coverage(段, 底本经) = SequenceMatcher 匹配块总长 / len(段)`，阈值 0.60。
   - 用「最长公共子串」会因句中二字之异而暴跌（例：源本「故有无之相生难易之相成…」对底本
     「故有無相生難易相成…」只有 0.46），覆盖率则 0.96。
4. **阈值必有两类误判，须人工 override**：
   | 类型 | 实例 | cov | 正解 |
   |---|---|---|---|
   | 短句带异文 → 误判为注 | 「飂兮似无所止。」（底本作「飂兮若無止」） | 0.50 | **经** |
   | 短句带异文 → 误判为注 | 「孰能损有余而奉不足於天下者，其唯道乎。」 | 0.59 | **经** |
   | 短句带异文 → 误判为注 | 「柔之胜刚，弱之胜强。」 | 0.50 | **经** |
   | 注文引经 → 误判为经 | 「道者，天地之始，岂得而名？」（实为注） | 0.60 | **注** |
   | 注文引经 → 误判为经 | 「认而有之，自私以失道，何德之有？」（实为注） | 0.62 | **注** |
5. **注可以跨段**，故「经/注 严格交替」先验不可靠：源本常有把一句注拆成两段者
   （如「…聪明为之衰，其於盲聋也何辫？」「无往而不／胜，所以为强。」）。只可用作**辅助校验**。
6. **校验口径**：源本经文覆盖底本经文 ≥0.80 且顺序不乱。低于 0.80 的章要逐个看——
   多为真异文（如 ch51、ch59、ch66、ch76），也可能是分篇错位。

## 三、对齐

1. **先 join 再 fold**：`fold(''.join(章节列表))`。
   直接把 list 传给 `zhconv.convert` 不报错，但返回原 list，`''.join` 后标点未去、繁体未转，
   导致 80/81 章误判为注。
2. **繁简折叠**：底本繁、参本简时，`zhconv.convert(s, 'zh-cn')` 折叠后方可比。折叠**只用于比对**。
3. **标点一律剥离**：本版与参本断句不同（`；`／`。`、`無名天地之始，`／`无名，天地之始。`），
   标点差异非文字异文，不录。
4. **倒文识别**：相邻 delete/insert 且核心互为**严格变位词**（sorted 相等）且长度 ≥2。
   - 严格条件会漏掉带换字的倒文：「持而保之／宝而持之」「弱之勝強，柔之勝剛」→ 归入特识人工补。
   - 放宽到「字集重叠 ≥0.5」会误报（曾把 ch31、ch32、ch78 的无关 delete/insert 配成倒文）。
5. **去重键**：脱文/衍文按「所脱/所衍之文字」去重（同一章 6 处增「之」合为 1 条 `n=6`）；
   异文按（底本, 源本）。条目数 ≠ 逐处数，报告里两个都要给。

## 四、人工裁断（机械层判不出、必须写特识者）

| 类型 | 判法 | 本次实例 |
|---|---|---|
| **涉上而误复** | 源本一处与上句重出且文义不属；查源本**自注**是否引及该句，引及即定 | ch14 源本「故復歸於無物」重出，夺「是謂無狀之狀，無物之象，是謂惚恍」（源本注正引此句） |
| **形近致讹** | 源本出现不成文之字 | ch23「況」讹「瓦」；ch32「川谷」讹「川各」、「搏」讹「传」 |
| **羼经入注** | 底本整句经文，源本不别出为经而见其注首/注末 | ch51「是以萬物莫不尊道而貴德」、ch59「是謂深根固柢，長生久視之道」、ch66「以其不爭，故天下莫能與之爭」→ 一律**两存待考** |
| **真倒文** | 因换字致机械层漏检 | ch41「進道若退」↔「夷道若颣」；ch67「持而保之」↔「宝而持之」；ch78「弱之勝強，柔之勝剛」 |
| **羼入讹文** | 源本中段出现不成句之窜文 | ch31「另外而非难是以」七字羼入 |

**定案强度**：众本＋他书＋文例交汇＝铁案；三路＝稳案；二路＝疑案（存疑语式）；不足＝阙疑（只著录）。
本次 ch14 判为**疑案**（源本经文夺句可定，但「何以至此」二说并存）。
